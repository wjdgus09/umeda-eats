# 우메다 · 도톤보리 52곳

오사카 우메다 숙소 기준 도보·지하철 1~2정거장 안의 식당 22곳 / 카페 13곳에,
장르(돈카츠·라멘·카레·스시·우동·야키니쿠)별로 다시 고른 우메다 7곳 / 난바·도톤보리 10곳을 더했습니다.

선정 기준: 리뷰 수·평점, 현지인 비중, 전 좌석 금연, 소셜 후기(광고 제외), 영업 여부.
기준에 걸려 제외한 곳은 페이지 하단에 이유와 함께 기록했습니다.

`index.html` 한 파일로 완결된 정적 페이지입니다.
